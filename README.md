# Credit Card Validator

## Описание

Учебный проект по основам Go. CLI-приложение проверяет корректность введеного в терминале номера банковской карты.

## Возможности

- Проверка введеного номера
- Проверка по алгоритму Луна

## Установка и запуск

```bash
go run ./main.go
```

## Примеры использования

```bash
go run .\main.go

Введите номер карты (или Enter для выхода): 4000123456789018

Введите номер карты (или Enter для выхода): 1234567890123456
```
